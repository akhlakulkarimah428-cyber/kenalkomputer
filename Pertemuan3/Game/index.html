📖 Buku Panduan Edukasi Microsoft Word
1. Kursor & Lembar Kerja Baru:

Garis tegak yang berkedip-kedip (|) disebut Kursor (Insertion Point). Posisi kursor menandakan di mana huruf atau simbol berikutnya akan muncul ketika kamu mengetik. Tombol Enter digunakan untuk membuat paragraf baru, dan Backspace untuk menghapus karakter di sebelah kiri kursor.

2. Jurus Sakti Menyimpan Dokumen (Ctrl + S):

Kombinasi tombol Ctrl + S adalah shortcut universal di Word untuk menyimpan (Save) dokumenmu secara cepat. Selalu tekan Ctrl + S setiap beberapa menit agar hasil tulisanmu aman dari mati lampu atau komputer restart tiba-tiba!

3. Format Teks BOLD (Ctrl + B):

Format Bold (Tebal) mengubah bobot huruf menjadi lebih tebal dan mencolok. Sangat dianjurkan untuk judul bab, subjudul, atau istilah penting agar pembaca langsung memahami inti informasi dengan cepat.

4. Header & Margin Kertas:

Margin adalah jarak kosong antara tepi kertas dengan teks isi (standar: 1 inci / 2.54 cm). Header adalah area di margin atas tempat mencantumkan judul dokumen, nomor halaman, atau nama penulis secara konsisten di seluruh lembar kerja.
